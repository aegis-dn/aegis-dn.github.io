## The project

Today's programming tools show nothing about the energy or carbon impact of the code a developer writes. In this project you put energy awareness into the everyday software workflow.

You will build tools that give real-time energy estimates inside the code editor, add automatic checks that catch energy regressions before release, and prove the toolchain on a real Open RAN application.

**What you will work on:**

- Develop an editor (IDE) plugin that gives developers real-time energy-cost estimates for their code.
- Add CI/CD gates that automatically test for energy regressions.
- Prove the toolchain by optimizing a representative Open RAN application.

**What you will deliver:**

- An IDE plugin for a popular editor (for example VS Code) that gives real-time energy feedback.
- A CI/CD framework that flags energy regressions against configurable thresholds.
- An Open RAN case study documenting the developer workflow and the resulting energy savings.
