## The project

There is a gap between a high-level goal like "cut carbon now" and the low-level, vendor-specific controls of a site's cooling, batteries, and compute hardware. In this project you close that gap.

You will build a control layer that takes "intents" and translates them into a coordinated set of actions across the site's physical assets. The models tune themselves online using reinforcement learning.

**What you will work on:**

- Design an intent language that captures carbon, flexibility, and cost.
- Break high-level intents down into commands for the physical assets.
- Tune the power-performance and thermal models online using reinforcement learning.

**What you will deliver:**

- Control software that turns intents into commands, with measured latency.
- A coordinated control library with documented power ramp rates from experiments.
- A telemetry system that reports headroom and runs without breaking service-level limits in test scenarios.
