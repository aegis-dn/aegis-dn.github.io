## The project

In this project you test the whole AEGIS platform in a live telecom site that runs both mobile-network functions and general AI workloads. This is the industrial pilot of the network.

You will show how the software-defined datacenter platform can coordinate these two very different kinds of work, delivering grid flexibility while never breaking the strict availability that a mobile network requires.

**What you will work on:**

- Develop xApps and rApps for the Open RAN RIC to change the power of telecom network functions.
- Build controllers that manage general AI workloads on the site's Multi-access Edge Computing (MEC) platform.
- Create one flexibility API that exposes the combined flexibility of both workload types to the fleet orchestrator.

**What you will deliver:**

- A set of validated control applications for the RIC and MEC platforms that can change site energy without affecting service.
- A public report on the coordinated control methods in the TDC pilot, including the potential for MW-scale flexibility while keeping network-availability targets.
