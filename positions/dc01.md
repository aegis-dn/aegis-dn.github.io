## The project

An edge datacenter can only sell fast grid services — for example, helping hold the grid's frequency steady within a second — if it can promise that doing so will never push the site past its own safety limits. In this project you build the safety foundation for that promise.

You will create a runtime verification framework: software that watches the datacenter as it runs and checks, against formal rules written in temporal logic, that every grid action stays inside safe operating bounds. This turns the site from an unpredictable load into a grid resource that operators can trust.

**What you will work on:**

- Create hierarchical control algorithms for Fast Frequency Response (FFR).
- Build a runtime safety-verification framework that uses temporal logic to enforce operational limits.
- Combine power electronics, IT load, and thermal systems in one validation platform.

**What you will deliver:**

- A verified control library with measured response times under two seconds.
- Runtime monitors that hold safety limits, such as a 20% power reserve, in simulated scenarios.
- A hardware-in-the-loop platform tested across a broad set of automated grid-event scenarios.
