## The project

A datacenter's flexibility is hard to use safely without one model that captures how its computing, electrical, and thermal parts behave together. In this project you build that model: a multi-domain digital twin.

The digital twin will continuously compute the site's "safe operating envelope" — a machine-readable limit that says how much power the site can change, and when, without breaking any rule. This makes the site's flexibility both predictable and verifiable for the rest of the AEGIS platform.

**What you will work on:**

- Build a framework that captures the coupled dynamics across very different timescales.
- Develop a multi-fidelity modeling approach covering power electronics, compute, thermal behavior, and workload.
- Export the model as semantic views, using ontologies, so other tools can read it.

**What you will deliver:**

- A digital twin with measured prediction errors.
- A toolkit that computes the safe envelope and respects operational limits.
- A semantic interface (API) shown to work with fleet orchestrators.
