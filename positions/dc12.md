## The project

When software agents run a fleet of datacenters on their own, every action must be authenticated, authorized, and auditable. In this project you build the cryptographic trust layer that makes autonomous operation safe.

You will give agents and workloads verifiable identities, bind their permissions to safety and energy limits, and produce tamper-evident proofs of what was done — proofs that grid operators can use for compliance and payment.

**What you will work on:**

- Build an agent identity model using decentralized identifiers (DIDs) and verifiable credentials.
- Design authorization that binds actions to safety and energy limits.
- Prototype proof-of-delivery that creates tamper-evident audit logs.

**What you will deliver:**

- A trust layer for authenticated communication between agents.
- An authorization system that blocks unauthorized actions.
- Complete audit trails for complex orchestration tasks.
