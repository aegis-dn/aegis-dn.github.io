# Contributing

Thank you for helping keep the AEGIS Doctoral Network website accurate. Most updates are simple Markdown edits.

## Regular Contributors

If you are an AEGIS PhD student, a partner representative who will update the site regularly, or another active contributor, please email your GitHub username to **aegis@compute.dtu.dk** so you can be added to the repository when appropriate.

## Occasional Edits

If you only need to edit the site once or a few times, you do not need repository access. Use either email or a pull request.

### Option 1: Email the Edited Markdown File

1. Open the relevant `.md` file in the GitHub repository.
2. Click the **Download raw file** icon, shown as a downward arrow.
3. Save the file, keeping the `.md` filename.
4. Edit it in a plain-text editor.
5. Email the edited file to **aegis@compute.dtu.dk**.

If the change is small, you can also email the exact text to add or replace, plus the page and section where it belongs.

### Option 2: Open a Pull Request

A pull request is a proposed change for review before it becomes part of the real website.

1. Open the relevant `.md` file in the GitHub repository.
2. Click the pencil/edit icon.
3. If GitHub says you do not have write access, let it fork the repository.
4. Make your Markdown edits in the browser.
5. Click **Commit changes**.
6. Choose the option to propose the change or create a pull request.
7. Submit the pull request.

The maintainer will review the pull request and merge it if everything looks correct.

## Editing Guidelines

- Edit only the relevant Markdown file when possible.
- Keep the text concise and factual.
- Do not edit build output such as `_site/`.
- Do not upload internal project documents, drafts, or private recruitment material.
